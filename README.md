# Svelte 5 Toolkit

Svelte 5 (runes) and Svelte 4 support for WebStorm and IntelliJ IDEA Ultimate (2026.2+).

- Highlighting: blocks, directives, components, `<svelte:*>` elements, TypeScript inside `{...}`, `lang="ts"` / `lang="scss"`.
- Folding and auto-close for `{#if}`, `{#each}`, `{#await}`, `{#key}`, `{#snippet}`.
- `svelte-language-server` + `typescript-svelte-plugin` (type checking, completion, diagnostics).
- Template ↔ `<script>` navigation, find usages, rename.
- SvelteKit: route-aware tab titles, icons, file nesting, related files.
- Hover docs for runes, blocks and directives; Svelte 4 syntax hints with migrate fixes.

Requires Node.js. If the project has no `svelte-language-server` in `node_modules`, it is downloaded from npm on first use. No data is collected.

Settings: *Languages & Frameworks | TypeScript | Svelte*.

## Build

- JDK 25. Gradle wrapper included.
- `gradlew test` — all tests. `-PsvelteCorpus=D:\path\to\app\src` also parses every `.svelte` under that folder.
- `gradlew runIde` — sandbox IDE with the plugin.
- `gradlew buildPlugin` — zip in `build/distributions`; install via Settings | Plugins | ⚙ | Install Plugin from Disk.
- `localIde` in `gradle.properties` points the build at an installed WebStorm; remove it to download `platformVersion` instead.

## Layout

- `src/main/grammar/_SvelteLexer.flex` — HTML lexer plus Svelte states, generated by the `generateLexer` task.
- `src/main/java/.../lexer/SvelteMustacheScanner.java` — splits `{...}` into keyword / expression / binding tokens (JS-aware).
- `src/main/kotlin/.../` — `lexer`, `parser`, `highlighting`, `editor`, `inspections`, `docs`, `psi` (template references), `kit` (SvelteKit), `service` (language server, TS plugin), `settings`.
- Notes and spec: `docs/`.
